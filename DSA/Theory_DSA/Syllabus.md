# DSA Theory Syllabus

## Structure

Each topic folder follows this naming: `XXX_Topic_Name/`

Each folder contains:

| File Type | Description |
|-----------|-------------|
| `Definition.md` | Data structure definition, properties, types, representations, memory layout, real-world analogies |
| `Basic_Operations.md` | Foundational operations — self-contained, covers every basic operation from scratch with theory and implementation |
| `Advanced_Operations.md` | Advanced and specialized operations — builds on basics, covers complex operations, optimizations, and edge cases |
| `<Sub_Topic>.md` | Exhaustive coverage of a sub-topic pattern — lists every known problem variation with theory, approach, and implementation |
| `Easy_Problems.md` | Easy-level problems with approach and solution |
| `Medium_Problems.md` | Medium-level problems with approach and solution |
| `Hard_Problems.md` | Hard-level problems with approach and solution |
