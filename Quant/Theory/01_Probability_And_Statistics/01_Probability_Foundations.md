# Probability Foundations

## Axioms of Probability

The modern mathematical foundation of probability theory rests on Kolmogorov's axioms, which provide a rigorous framework for probability spaces.

### Kolmogorov Axioms

A probability space $(\Omega, \mathcal{F}, \mathbb{P})$ consists of:
- **Sample space** $\Omega$: the set of all possible outcomes
- **Sigma-algebra** $\mathcal{F}$: a collection of subsets of $\Omega$ satisfying:
  1. $\Omega \in \mathcal{F}$
  2. If $A \in \mathcal{F}$, then $A^c \in \mathcal{F}$ (closed under complementation)
  3. If $A_1, A_2, \ldots \in \mathcal{F}$, then $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$ (closed under countable unions)
- **Probability measure** $\mathbb{P}: \mathcal{F} \to [0,1]$ satisfying:
  1. **Non-negativity**: $\mathbb{P}(A) \geq 0$ for all $A \in \mathcal{F}$
  2. **Normalization**: $\mathbb{P}(\Omega) = 1$
  3. **Countable additivity**: For disjoint events $A_1, A_2, \ldots \in \mathcal{F}$,
     $$\mathbb{P}\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} \mathbb{P}(A_i)$$

### Sigma-Algebras

A sigma-algebra $\mathcal{F}$ on $\Omega$ is a collection of subsets that is closed under complementation and countable unions. The smallest sigma-algebra containing a collection $\mathcal{C}$ is called the sigma-algebra generated by $\mathcal{C}$, denoted $\sigma(\mathcal{C})$.

For a discrete sample space $\Omega = \{\omega_1, \omega_2, \ldots\}$, the power set $2^{\Omega}$ forms a sigma-algebra. For continuous spaces like $\mathbb{R}$, the Borel sigma-algebra $\mathcal{B}(\mathbb{R})$ is generated by open intervals $(a,b)$.

### Properties of Probability Measures

From the axioms, we derive fundamental properties:

1. **Complement rule**: $\mathbb{P}(A^c) = 1 - \mathbb{P}(A)$
2. **Monotonicity**: If $A \subseteq B$, then $\mathbb{P}(A) \leq \mathbb{P}(B)$
3. **Finite additivity**: For disjoint events $A_1, \ldots, A_n$,
   $$\mathbb{P}\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} \mathbb{P}(A_i)$$
4. **Inclusion-exclusion principle**: For events $A$ and $B$,
   $$\mathbb{P}(A \cup B) = \mathbb{P}(A) + \mathbb{P}(B) - \mathbb{P}(A \cap B)$$
5. **Continuity from below**: If $A_1 \subseteq A_2 \subseteq \cdots$ and $A = \bigcup_{i=1}^{\infty} A_i$, then
   $$\mathbb{P}(A) = \lim_{n \to \infty} \mathbb{P}(A_n)$$
6. **Continuity from above**: If $A_1 \supseteq A_2 \supseteq \cdots$ and $A = \bigcap_{i=1}^{\infty} A_i$, then
   $$\mathbb{P}(A) = \lim_{n \to \infty} \mathbb{P}(A_n)$$

## Conditional Probability

### Definition

For events $A$ and $B$ with $\mathbb{P}(B) > 0$, the conditional probability of $A$ given $B$ is:

$$\mathbb{P}(A|B) = \frac{\mathbb{P}(A \cap B)}{\mathbb{P}(B)}$$

This definition satisfies the probability axioms when restricted to the conditional space. The conditional probability measure $\mathbb{P}(\cdot|B)$ is a valid probability measure on the sigma-algebra $\mathcal{F}$.

### Law of Total Probability

For a partition $\{B_1, B_2, \ldots\}$ of $\Omega$ (disjoint events whose union is $\Omega$), and any event $A$:

$$\mathbb{P}(A) = \sum_{i=1}^{\infty} \mathbb{P}(A|B_i)\mathbb{P}(B_i)$$

For a finite partition $\{B_1, \ldots, B_n\}$:

$$\mathbb{P}(A) = \sum_{i=1}^{n} \mathbb{P}(A|B_i)\mathbb{P}(B_i)$$

### Bayes' Theorem

Bayes' theorem provides a mechanism for updating probabilities based on new information:

$$\mathbb{P}(B|A) = \frac{\mathbb{P}(A|B)\mathbb{P}(B)}{\mathbb{P}(A)}$$

Using the law of total probability, this becomes:

$$\mathbb{P}(B_i|A) = \frac{\mathbb{P}(A|B_i)\mathbb{P}(B_i)}{\sum_{j=1}^{n} \mathbb{P}(A|B_j)\mathbb{P}(B_j)}$$

**Example**: In signal detection, if $\mathbb{P}(\text{signal}) = 0.1$ and the detector has false positive rate $\mathbb{P}(\text{alarm}|\text{no signal}) = 0.05$ and true positive rate $\mathbb{P}(\text{alarm}|\text{signal}) = 0.9$, then:

$$\mathbb{P}(\text{signal}|\text{alarm}) = \frac{0.9 \times 0.1}{0.9 \times 0.1 + 0.05 \times 0.9} = \frac{0.09}{0.135} = \frac{2}{3}$$

## Independence

### Definition

Events $A$ and $B$ are independent if:

$$\mathbb{P}(A \cap B) = \mathbb{P}(A)\mathbb{P}(B)$$

Equivalently, if $\mathbb{P}(B) > 0$, then $\mathbb{P}(A|B) = \mathbb{P}(A)$.

A collection of events $\{A_1, A_2, \ldots, A_n\}$ is pairwise independent if $\mathbb{P}(A_i \cap A_j) = \mathbb{P}(A_i)\mathbb{P}(A_j)$ for all $i \neq j$.

The events are mutually independent if for any subset $\{i_1, \ldots, i_k\}$:

$$\mathbb{P}\left(\bigcap_{j=1}^{k} A_{i_j}\right) = \prod_{j=1}^{k} \mathbb{P}(A_{i_j})$$

### Conditional Independence

Events $A$ and $B$ are conditionally independent given $C$ if:

$$\mathbb{P}(A \cap B|C) = \mathbb{P}(A|C)\mathbb{P}(B|C)$$

This is equivalent to $\mathbb{P}(A|B \cap C) = \mathbb{P}(A|C)$ when $\mathbb{P}(B \cap C) > 0$.

**Example**: In portfolio theory, asset returns $R_1$ and $R_2$ may be independent unconditionally, but conditionally dependent given market regime $M$:

$$\mathbb{P}(R_1, R_2|M = \text{bear}) \neq \mathbb{P}(R_1|M = \text{bear})\mathbb{P}(R_2|M = \text{bear})$$

## Combinatorics

### Permutations

The number of ways to arrange $n$ distinct objects is $n! = n \times (n-1) \times \cdots \times 2 \times 1$.

The number of permutations of $n$ objects taken $r$ at a time (ordered selection without replacement):

$$P(n,r) = \frac{n!}{(n-r)!} = n(n-1)\cdots(n-r+1)$$

### Combinations

The number of ways to choose $r$ objects from $n$ distinct objects (unordered selection without replacement):

$$\binom{n}{r} = \frac{n!}{r!(n-r)!} = \frac{P(n,r)}{r!}$$

Properties:
- $\binom{n}{r} = \binom{n}{n-r}$ (symmetry)
- $\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$ (Pascal's identity)
- $\sum_{r=0}^{n} \binom{n}{r} = 2^n$ (binomial theorem with $x=y=1$)

### Multinomial Coefficient

For partitioning $n$ objects into $k$ groups of sizes $n_1, n_2, \ldots, n_k$:

$$\binom{n}{n_1, n_2, \ldots, n_k} = \frac{n!}{n_1!n_2!\cdots n_k!}$$

### Inclusion-Exclusion Principle

For events $A_1, A_2, \ldots, A_n$:

$$\mathbb{P}\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} \mathbb{P}(A_i) - \sum_{1 \leq i < j \leq n} \mathbb{P}(A_i \cap A_j) + \sum_{1 \leq i < j < k \leq n} \mathbb{P}(A_i \cap A_j \cap A_k) - \cdots + (-1)^{n+1}\mathbb{P}\left(\bigcap_{i=1}^{n} A_i\right)$$

The general form:

$$\mathbb{P}\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{k=1}^{n} (-1)^{k+1} \sum_{1 \leq i_1 < \cdots < i_k \leq n} \mathbb{P}\left(\bigcap_{j=1}^{k} A_{i_j}\right)$$

## Classic Problems

### Birthday Problem

What is the probability that at least two people in a group of $n$ share the same birthday? Assuming 365 equally likely birthdays:

$$\mathbb{P}(\text{at least one match}) = 1 - \mathbb{P}(\text{all different}) = 1 - \frac{365 \times 364 \times \cdots \times (365-n+1)}{365^n}$$

For $n = 23$, this probability exceeds $0.5$. The approximation for large $n$:

$$\mathbb{P}(\text{at least one match}) \approx 1 - e^{-n(n-1)/(2 \times 365)}$$

### Coupon Collector Problem

Expected number of trials to collect all $n$ distinct coupons:

$$E[T] = n \sum_{i=1}^{n} \frac{1}{i} = nH_n \approx n(\ln n + \gamma)$$

where $H_n$ is the $n$-th harmonic number and $\gamma \approx 0.577$ is Euler's constant.

The probability of collecting all coupons in exactly $t$ trials:

$$\mathbb{P}(T = t) = \frac{n!}{n^t} \binom{t-1}{n-1}$$

### Matching Problem (Derangements)

The probability that a random permutation of $n$ objects has no fixed points (derangement):

$$D_n = n! \sum_{k=0}^{n} \frac{(-1)^k}{k!}$$

As $n \to \infty$, $\frac{D_n}{n!} \to \frac{1}{e} \approx 0.368$.

### Ballot Problem

If candidate $A$ receives $a$ votes and candidate $B$ receives $b$ votes ($a > b$), the probability that $A$ is always ahead in the count:

$$\mathbb{P}(A \text{ always ahead}) = \frac{a-b}{a+b}$$

This result follows from the reflection principle and has applications in path counting problems.

## Applications in Quantitative Finance

### Risk Aggregation

When aggregating risks from multiple sources, independence assumptions are critical. If portfolio losses $L_1, \ldots, L_n$ are independent with distributions $F_1, \ldots, F_n$, the total loss distribution is:

$$F_L(x) = \mathbb{P}\left(\sum_{i=1}^{n} L_i \leq x\right)$$

This requires convolution, which is computationally intensive. Under independence, the characteristic function factorizes:

$$\phi_L(t) = \prod_{i=1}^{n} \phi_{L_i}(t)$$

### Model Selection

Bayesian model averaging uses conditional probabilities to weight different models:

$$\mathbb{P}(\text{model } M_i|\text{data}) = \frac{\mathbb{P}(\text{data}|M_i)\mathbb{P}(M_i)}{\sum_{j=1}^{k} \mathbb{P}(\text{data}|M_j)\mathbb{P}(M_j)}$$

This provides a principled approach to combining forecasts from multiple models, accounting for model uncertainty.

### Stress Testing

Conditional probabilities are essential for stress testing. The probability of portfolio loss exceeding threshold $L$ given stress scenario $S$:

$$\mathbb{P}(L > \ell|S) = \frac{\mathbb{P}(L > \ell, S)}{\mathbb{P}(S)}$$

This allows regulators and risk managers to assess tail risk under adverse conditions.
