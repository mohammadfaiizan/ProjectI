# Measure Theory and Advanced Probability

## Sigma-Algebras

A sigma-algebra (or $\sigma$-algebra) $\mathcal{F}$ on a set $\Omega$ is a collection of subsets of $\Omega$ satisfying:

1. $\Omega \in \mathcal{F}$
2. If $A \in \mathcal{F}$, then $A^c \in \mathcal{F}$ (closed under complement)
3. If $A_1, A_2, \ldots \in \mathcal{F}$, then $\bigcup_{i=1}^{\infty} A_i \in \mathcal{F}$ (closed under countable unions)

From (1) and (2), $\emptyset \in \mathcal{F}$. From (2) and (3), $\mathcal{F}$ is also closed under countable intersections.

**Examples**:
- **Trivial sigma-algebra**: $\mathcal{F} = \{\emptyset, \Omega\}$
- **Power set**: $\mathcal{F} = 2^{\Omega}$ (all subsets)
- **Borel sigma-algebra**: For $\Omega = \mathbb{R}$, the Borel sigma-algebra $\mathcal{B}(\mathbb{R})$ is the smallest sigma-algebra containing all open intervals. It is generated by intervals $(a,b]$, $a < b$.

### Generated Sigma-Algebra

For a collection $\mathcal{C}$ of subsets of $\Omega$, the sigma-algebra generated by $\mathcal{C}$, denoted $\sigma(\mathcal{C})$, is the smallest sigma-algebra containing $\mathcal{C}$.

**Example**: For a random variable $X: \Omega \to \mathbb{R}$, the sigma-algebra generated by $X$ is:

$$\sigma(X) = \{X^{-1}(B) : B \in \mathcal{B}(\mathbb{R})\}$$

This represents the information contained in $X$.

### Measurable Space

A pair $(\Omega, \mathcal{F})$ where $\Omega$ is a set and $\mathcal{F}$ is a sigma-algebra on $\Omega$ is called a measurable space.

## Measures

A measure $\mu$ on a measurable space $(\Omega, \mathcal{F})$ is a function $\mu: \mathcal{F} \to [0, \infty]$ satisfying:

1. $\mu(\emptyset) = 0$
2. Countable additivity: For disjoint sets $A_1, A_2, \ldots \in \mathcal{F}$:

$$\mu\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} \mu(A_i)$$

A measure space is a triple $(\Omega, \mathcal{F}, \mu)$.

### Probability Measure

A probability measure $\mathbb{P}$ is a measure with $\mathbb{P}(\Omega) = 1$. A probability space is $(\Omega, \mathcal{F}, \mathbb{P})$.

**Properties**:
- $\mathbb{P}(A^c) = 1 - \mathbb{P}(A)$
- If $A \subseteq B$, then $\mathbb{P}(A) \leq \mathbb{P}(B)$
- $\mathbb{P}(A \cup B) = \mathbb{P}(A) + \mathbb{P}(B) - \mathbb{P}(A \cap B)$
- Continuity from below: If $A_1 \subseteq A_2 \subseteq \cdots$ and $A = \bigcup_{i=1}^{\infty} A_i$, then $\mathbb{P}(A) = \lim_{n \to \infty} \mathbb{P}(A_n)$
- Continuity from above: If $A_1 \supseteq A_2 \supseteq \cdots$ and $A = \bigcap_{i=1}^{\infty} A_i$, then $\mathbb{P}(A) = \lim_{n \to \infty} \mathbb{P}(A_n)$

### Lebesgue Measure

On $\mathbb{R}$, the Lebesgue measure $\lambda$ extends length to a larger class of sets. For an interval $(a,b]$:

$$\lambda((a,b]) = b - a$$

The Lebesgue measure is translation-invariant: $\lambda(A + x) = \lambda(A)$ for any set $A$ and $x \in \mathbb{R}$.

### Complete Measure Space

A measure space $(\Omega, \mathcal{F}, \mu)$ is complete if every subset of a null set (set of measure zero) is measurable. The Lebesgue measure space is the completion of the Borel measure space.

## Measurable Functions

A function $f: (\Omega_1, \mathcal{F}_1) \to (\Omega_2, \mathcal{F}_2)$ is measurable if:

$$f^{-1}(B) \in \mathcal{F}_1 \quad \forall B \in \mathcal{F}_2$$

**Example**: A random variable $X: \Omega \to \mathbb{R}$ is measurable if $X^{-1}(B) \in \mathcal{F}$ for all Borel sets $B \in \mathcal{B}(\mathbb{R})$.

**Properties**:
- Composition of measurable functions is measurable
- Sum, product, and limit of measurable functions are measurable
- If $f$ and $g$ are measurable, then $\max(f,g)$ and $\min(f,g)$ are measurable

## Lebesgue Integration

### Simple Functions

A simple function is a finite linear combination of indicator functions:

$$s = \sum_{i=1}^{n} a_i \mathbf{1}_{A_i}$$

where $A_i \in \mathcal{F}$ are disjoint and $a_i \in \mathbb{R}$.

The Lebesgue integral of a non-negative simple function is:

$$\int s d\mu = \sum_{i=1}^{n} a_i \mu(A_i)$$

### Non-Negative Functions

For a non-negative measurable function $f$, define:

$$\int f d\mu = \sup\left\{\int s d\mu : s \text{ simple}, 0 \leq s \leq f\right\}$$

### General Functions

For a measurable function $f$, write $f = f^+ - f^-$ where $f^+ = \max(f, 0)$ and $f^- = \max(-f, 0)$. Then:

$$\int f d\mu = \int f^+ d\mu - \int f^- d\mu$$

provided at least one integral is finite. If both are finite, $f$ is integrable.

### Properties of Lebesgue Integral

- **Linearity**: $\int (af + bg) d\mu = a \int f d\mu + b \int g d\mu$
- **Monotonicity**: If $f \leq g$ almost everywhere, then $\int f d\mu \leq \int g d\mu$
- **Triangle inequality**: $\left|\int f d\mu\right| \leq \int |f| d\mu$

### Comparison with Riemann Integral

The Lebesgue integral generalizes the Riemann integral:
- Every Riemann-integrable function is Lebesgue-integrable with the same value
- The Lebesgue integral handles more functions (e.g., indicator of rationals)
- Better convergence theorems (monotone convergence, dominated convergence)

## Absolute Continuity and Radon-Nikodym Theorem

### Absolute Continuity

A measure $\nu$ is absolutely continuous with respect to a measure $\mu$, written $\nu \ll \mu$, if:

$$\mu(A) = 0 \implies \nu(A) = 0$$

**Example**: If $f$ is a non-negative measurable function, then:

$$\nu(A) = \int_A f d\mu$$

defines a measure $\nu$ with $\nu \ll \mu$.

### Radon-Nikodym Theorem

If $\nu \ll \mu$ and $\mu$ is $\sigma$-finite, then there exists a non-negative measurable function $f$ (unique up to $\mu$-null sets) such that:

$$\nu(A) = \int_A f d\mu \quad \forall A \in \mathcal{F}$$

The function $f$ is called the Radon-Nikodym derivative and denoted:

$$f = \frac{d\nu}{d\mu}$$

**Financial interpretation**: In risk-neutral pricing, if $Q$ is the risk-neutral measure and $\mathbb{P}$ is the physical measure with $Q \ll \mathbb{P}$, then:

$$\frac{dQ}{d\mathbb{P}}$$

is the Radon-Nikodym derivative (state price density). The price of a derivative is:

$$V_0 = E^Q[e^{-rT} V_T] = E^{\mathbb{P}}\left[\frac{dQ}{d\mathbb{P}} e^{-rT} V_T\right]$$

### Chain Rule

If $\nu \ll \mu \ll \lambda$, then:

$$\frac{d\nu}{d\lambda} = \frac{d\nu}{d\mu} \cdot \frac{d\mu}{d\lambda}$$

### Change of Measure

For a measurable function $g$:

$$\int g d\nu = \int g \frac{d\nu}{d\mu} d\mu$$

This is the change of measure formula.

## Filtrations and Adapted Processes

### Filtration

A filtration $\{\mathcal{F}_t\}_{t \geq 0}$ is an increasing family of sigma-algebras:

$$\mathcal{F}_s \subseteq \mathcal{F}_t \quad \text{for } s \leq t$$

$\mathcal{F}_t$ represents information available up to time $t$.

**Example**: For a stochastic process $\{X_t\}$, the natural filtration is:

$$\mathcal{F}_t = \sigma(X_s : s \leq t)$$

### Adapted Process

A stochastic process $\{X_t\}$ is adapted to a filtration $\{\mathcal{F}_t\}$ if $X_t$ is $\mathcal{F}_t$-measurable for all $t$.

**Interpretation**: $X_t$ depends only on information available up to time $t$.

### Predictable Process

A process $\{H_t\}$ is predictable if $H_t$ is $\mathcal{F}_{t-}$-measurable, where $\mathcal{F}_{t-} = \sigma(\bigcup_{s < t} \mathcal{F}_s)$.

**Interpretation**: $H_t$ is known just before time $t$, enabling "pre-visible" trading strategies.

## Conditional Expectation (Rigorous Definition)

### Definition

For a random variable $X$ with $E[|X|] < \infty$ and a sigma-algebra $\mathcal{G} \subseteq \mathcal{F}$, the conditional expectation $E[X | \mathcal{G}]$ is the unique (up to almost sure equality) $\mathcal{G}$-measurable random variable satisfying:

$$\int_A E[X | \mathcal{G}] d\mathbb{P} = \int_A X d\mathbb{P} \quad \forall A \in \mathcal{G}$$

**Existence**: Guaranteed by the Radon-Nikodym theorem. Define $\nu(A) = \int_A X d\mathbb{P}$ for $A \in \mathcal{G}$. Then $\nu \ll \mathbb{P}|_{\mathcal{G}}$, so $\frac{d\nu}{d\mathbb{P}|_{\mathcal{G}}}$ exists and equals $E[X | \mathcal{G}]$.

### Properties

1. **Linearity**: $E[aX + bY | \mathcal{G}] = aE[X | \mathcal{G}] + bE[Y | \mathcal{G}]$
2. **Tower property**: If $\mathcal{H} \subseteq \mathcal{G}$, then $E[E[X | \mathcal{G}] | \mathcal{H}] = E[X | \mathcal{H}]$
3. **Taking out what's known**: If $Y$ is $\mathcal{G}$-measurable and $E[|XY|] < \infty$, then $E[XY | \mathcal{G}] = Y E[X | \mathcal{G}]$
4. **Independence**: If $X$ is independent of $\mathcal{G}$, then $E[X | \mathcal{G}] = E[X]$
5. **Jensen's inequality**: If $\varphi$ is convex, then $\varphi(E[X | \mathcal{G}]) \leq E[\varphi(X) | \mathcal{G}]$

### Conditional Expectation Given a Random Variable

For $E[X | Y]$, use $\mathcal{G} = \sigma(Y)$:

$$E[X | Y] = E[X | \sigma(Y)]$$

By the Doob-Dynkin lemma, $E[X | Y]$ can be written as $g(Y)$ for some measurable function $g$.

## Convergence Theorems

### Monotone Convergence Theorem

If $0 \leq X_1 \leq X_2 \leq \cdots$ and $X_n \to X$ almost surely, then:

$$\lim_{n \to \infty} \int X_n d\mu = \int X d\mu$$

**Application**: Enables interchanging limit and integral for monotone sequences.

### Fatou's Lemma

For non-negative measurable functions $X_n$:

$$\int \liminf_{n \to \infty} X_n d\mu \leq \liminf_{n \to \infty} \int X_n d\mu$$

**Corollary**: If $X_n \geq Y$ with $E[|Y|] < \infty$, then:

$$E[\liminf_{n \to \infty} X_n] \leq \liminf_{n \to \infty} E[X_n]$$

### Dominated Convergence Theorem

If $X_n \to X$ almost surely, $|X_n| \leq Y$ for all $n$ with $E[Y] < \infty$, then:

$$\lim_{n \to \infty} \int X_n d\mu = \int X d\mu$$

and:

$$\lim_{n \to \infty} E[X_n] = E[X]$$

**Application**: Justifies interchanging limit and expectation under boundedness conditions.

**Example**: For a sequence of derivatives with payoffs $V_T^{(n)} \to V_T$ and $|V_T^{(n)}| \leq K$ (bounded), the prices converge:

$$\lim_{n \to \infty} E^Q[e^{-rT} V_T^{(n)}] = E^Q[e^{-rT} V_T]$$

### Bounded Convergence Theorem

If $X_n \to X$ almost surely and $|X_n| \leq M$ for some constant $M$, then:

$$\lim_{n \to \infty} E[X_n] = E[X]$$

This is a special case of dominated convergence.

### Uniform Integrability

A sequence $\{X_n\}$ is uniformly integrable if:

$$\lim_{M \to \infty} \sup_n E[|X_n| \mathbf{1}_{|X_n| > M}] = 0$$

**Vitali's Convergence Theorem**: If $X_n \to X$ in probability and $\{X_n\}$ is uniformly integrable, then $E[|X_n - X|] \to 0$ and $E[X_n] \to E[X]$.

## Connection to Mathematical Finance

### Risk-Neutral Measure

In a complete market, there exists a unique risk-neutral (martingale) measure $Q$ equivalent to the physical measure $\mathbb{P}$ ($Q \sim \mathbb{P}$ means $Q \ll \mathbb{P}$ and $\mathbb{P} \ll Q$).

The Radon-Nikodym derivative $\frac{dQ}{d\mathbb{P}}$ is the state price density. Under $Q$, discounted asset prices are martingales:

$$E^Q\left[\frac{S_T}{B_T} \Big| \mathcal{F}_t\right] = \frac{S_t}{B_t}$$

where $B_t$ is the risk-free asset.

### Girsanov's Theorem

Girsanov's theorem describes how Brownian motion transforms under a change of measure. If:

$$\frac{dQ}{d\mathbb{P}}\Big|_{\mathcal{F}_t} = \exp\left(-\int_0^t \theta_s dW_s - \frac{1}{2}\int_0^t \theta_s^2 ds\right)$$

then under $Q$, the process:

$$\tilde{W}_t = W_t + \int_0^t \theta_s ds$$

is a Brownian motion.

**Application**: In the Black-Scholes model, changing from physical to risk-neutral measure shifts the drift from $\mu$ to $r$:

$$\frac{dS_t}{S_t} = \mu dt + \sigma dW_t^{\mathbb{P}} = r dt + \sigma dW_t^Q$$

### Martingale Representation

In a complete market, any square-integrable martingale $M_t$ adapted to the Brownian filtration can be represented as:

$$M_t = M_0 + \int_0^t H_s dW_s$$

for some predictable process $H$. This enables perfect hedging.

### Fundamental Theorem of Asset Pricing

**First Fundamental Theorem**: A market is arbitrage-free if and only if there exists a risk-neutral measure.

**Second Fundamental Theorem**: A market is complete if and only if the risk-neutral measure is unique.

These theorems rely on measure-theoretic concepts:
- Equivalent measures
- Radon-Nikodym derivatives
- Martingale representation

### Stochastic Integration

The Itô integral:

$$\int_0^t H_s dW_s$$

is defined using measure theory. For a simple process $H$, the integral is:

$$\int_0^t H_s dW_s = \sum_{i=0}^{n-1} H_{t_i}(W_{t_{i+1}} - W_{t_i})$$

For general predictable $H$ with $E[\int_0^T H_s^2 ds] < \infty$, the integral is extended using $L^2$ convergence and the Itô isometry:

$$E\left[\left(\int_0^T H_s dW_s\right)^2\right] = E\left[\int_0^T H_s^2 ds\right]$$

### Conditional Expectations in Pricing

The price of a derivative at time $t$ is:

$$V_t = E^Q\left[e^{-r(T-t)} V_T \Big| \mathcal{F}_t\right]$$

This conditional expectation is:
- $\mathcal{F}_t$-measurable (adapted)
- A $Q$-martingale (by tower property)
- The unique arbitrage-free price

The tower property ensures consistency:

$$V_s = E^Q[V_t | \mathcal{F}_s] \quad \text{for } s \leq t$$

## Advanced Topics

### Regular Conditional Probabilities

A regular conditional probability $\mathbb{P}(A | \mathcal{G})(\omega)$ is a version of conditional probability that is a probability measure for each $\omega$. Not all conditional probabilities are regular, but they exist under mild conditions (Polish spaces).

### Disintegration Theorem

Relates joint distributions to conditional distributions and marginals, generalizing $f_{X,Y}(x,y) = f_{Y|X}(y|x) f_X(x)$.

### Product Measures and Fubini's Theorem

For product spaces $(\Omega_1 \times \Omega_2, \mathcal{F}_1 \otimes \mathcal{F}_2)$, Fubini's theorem allows interchanging order of integration:

$$\int_{\Omega_1 \times \Omega_2} f d(\mu_1 \times \mu_2) = \int_{\Omega_1} \left(\int_{\Omega_2} f(\omega_1, \omega_2) d\mu_2(\omega_2)\right) d\mu_1(\omega_1)$$

provided $f$ is integrable.

Measure theory provides the rigorous foundation for modern probability theory and mathematical finance, enabling precise statements about convergence, integration, and conditional expectations that are essential for derivative pricing and risk management.
