# Expectation, Variance, and Moments

## Expectation

The expectation (expected value) of a random variable $X$ is defined as:

$$E[X] = \begin{cases}
\sum_{x} x \cdot p_X(x) & \text{if } X \text{ is discrete} \\
\int_{-\infty}^{\infty} x f_X(x) dx & \text{if } X \text{ is continuous}
\end{cases}$$

provided the sum or integral converges absolutely. In measure-theoretic terms, for a probability space $(\Omega, \mathcal{F}, \mathbb{P})$:

$$E[X] = \int_{\Omega} X(\omega) d\mathbb{P}(\omega) = \int_{\mathbb{R}} x dF_X(x)$$

where $F_X$ is the cumulative distribution function of $X$.

### Linearity of Expectation

Expectation is a linear operator. For random variables $X$ and $Y$ and constants $a, b \in \mathbb{R}$:

$$E[aX + bY] = aE[X] + bE[Y]$$

This holds regardless of whether $X$ and $Y$ are independent. Linearity extends to finite sums:

$$E\left[\sum_{i=1}^{n} a_i X_i\right] = \sum_{i=1}^{n} a_i E[X_i]$$

**Example**: For a portfolio with $n$ assets, if $X_i$ is the return of asset $i$ and $w_i$ is the portfolio weight, the expected portfolio return is:

$$E[R_p] = E\left[\sum_{i=1}^{n} w_i X_i\right] = \sum_{i=1}^{n} w_i E[X_i]$$

### Expectation of Functions

For a measurable function $g: \mathbb{R} \to \mathbb{R}$, the expectation of $g(X)$ is:

$$E[g(X)] = \begin{cases}
\sum_{x} g(x) p_X(x) & \text{if } X \text{ is discrete} \\
\int_{-\infty}^{\infty} g(x) f_X(x) dx & \text{if } X \text{ is continuous}
\end{cases}$$

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$, we have:

$$E[e^X] = e^{\mu + \frac{\sigma^2}{2}}$$

This follows from the moment generating function of the normal distribution.

### Conditional Expectation

The conditional expectation of $X$ given an event $A$ with $\mathbb{P}(A) > 0$ is:

$$E[X | A] = \frac{E[X \mathbf{1}_A]}{\mathbb{P}(A)} = \frac{\int_A X d\mathbb{P}}{\mathbb{P}(A)}$$

For discrete $X$:

$$E[X | A] = \sum_{x} x \cdot \mathbb{P}(X = x | A)$$

For continuous $X$ with conditional density $f_{X|A}(x)$:

$$E[X | A] = \int_{-\infty}^{\infty} x f_{X|A}(x) dx$$

### Conditional Expectation Given a Random Variable

The conditional expectation $E[X | Y]$ is a random variable that is measurable with respect to the sigma-algebra generated by $Y$, $\sigma(Y)$. It satisfies:

$$E[E[X | Y]] = E[X]$$

and for any measurable function $h$:

$$E[X h(Y)] = E[E[X | Y] h(Y)]$$

**Example**: If $(X, Y)$ is bivariate normal with correlation $\rho$, then:

$$E[X | Y = y] = \mu_X + \rho \frac{\sigma_X}{\sigma_Y}(y - \mu_Y)$$

### Iterated Expectation (Tower Property)

The tower property states that for nested sigma-algebras $\mathcal{G}_1 \subseteq \mathcal{G}_2$:

$$E[E[X | \mathcal{G}_2] | \mathcal{G}_1] = E[X | \mathcal{G}_1]$$

In particular, for random variables:

$$E[E[X | Y, Z] | Y] = E[X | Y]$$

This is fundamental in dynamic programming and optimal stopping problems.

**Example**: In a multi-period portfolio problem, if $X$ is terminal wealth and $\mathcal{F}_t$ is the information available at time $t$:

$$E[X | \mathcal{F}_0] = E[E[X | \mathcal{F}_1] | \mathcal{F}_0] = E[E[E[X | \mathcal{F}_2] | \mathcal{F}_1] | \mathcal{F}_0] = \cdots$$

## Variance and Covariance

### Variance

The variance of a random variable $X$ measures its dispersion around the mean:

$$\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

The standard deviation is:

$$\sigma_X = \sqrt{\text{Var}(X)}$$

**Properties**:
- $\text{Var}(aX + b) = a^2 \text{Var}(X)$ for constants $a, b$
- $\text{Var}(X) \geq 0$, with equality if and only if $X$ is almost surely constant
- $\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X, Y)$

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$:

$$\text{Var}(X) = \sigma^2$$

For $X \sim \text{Binomial}(n, p)$:

$$\text{Var}(X) = np(1-p)$$

### Covariance

The covariance between random variables $X$ and $Y$ is:

$$\text{Cov}(X, Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]$$

**Properties**:
- $\text{Cov}(X, Y) = \text{Cov}(Y, X)$ (symmetry)
- $\text{Cov}(X, X) = \text{Var}(X)$
- $\text{Cov}(aX + b, cY + d) = ac \text{Cov}(X, Y)$
- $\text{Cov}(X + Y, Z) = \text{Cov}(X, Z) + \text{Cov}(Y, Z)$ (bilinearity)

If $X$ and $Y$ are independent, then $\text{Cov}(X, Y) = 0$. The converse is not true in general.

### Correlation

The correlation coefficient is the normalized covariance:

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} = \frac{E[(X - E[X])(Y - E[Y])]}{\sqrt{E[(X - E[X])^2] E[(Y - E[Y])^2]}}$$

**Properties**:
- $-1 \leq \rho_{XY} \leq 1$ (Cauchy-Schwarz inequality)
- $\rho_{XY} = 1$ if and only if $Y = aX + b$ with $a > 0$
- $\rho_{XY} = -1$ if and only if $Y = aX + b$ with $a < 0$
- $\rho_{XY} = 0$ if $X$ and $Y$ are uncorrelated

**Example**: For a portfolio with two assets:

$$\text{Var}(w_1 X_1 + w_2 X_2) = w_1^2 \sigma_1^2 + w_2^2 \sigma_2^2 + 2w_1 w_2 \rho_{12} \sigma_1 \sigma_2$$

where $\rho_{12}$ is the correlation between returns.

### Variance-Covariance Matrix

For a random vector $\mathbf{X} = (X_1, \ldots, X_n)^T$, the variance-covariance matrix is:

$$\boldsymbol{\Sigma} = E[(\mathbf{X} - \boldsymbol{\mu})(\mathbf{X} - \boldsymbol{\mu})^T]$$

where $\boldsymbol{\mu} = E[\mathbf{X}]$. The $(i,j)$-th entry is:

$$\Sigma_{ij} = \text{Cov}(X_i, X_j)$$

The matrix $\boldsymbol{\Sigma}$ is symmetric and positive semidefinite.

## Moments

### Raw Moments

The $k$-th raw moment of $X$ is:

$$\mu_k' = E[X^k]$$

The first raw moment is the mean: $\mu_1' = E[X] = \mu$.

### Central Moments

The $k$-th central moment is:

$$\mu_k = E[(X - \mu)^k]$$

- $\mu_1 = 0$
- $\mu_2 = \text{Var}(X)$
- $\mu_3$ relates to skewness
- $\mu_4$ relates to kurtosis

### Skewness

Skewness measures asymmetry:

$$\gamma_1 = \frac{\mu_3}{\sigma^3} = \frac{E[(X - \mu)^3]}{\sigma^3}$$

**Interpretation**:
- $\gamma_1 > 0$: right-skewed (long right tail)
- $\gamma_1 < 0$: left-skewed (long left tail)
- $\gamma_1 = 0$: symmetric distribution

**Financial interpretation**: Positive skewness indicates frequent small losses and occasional large gains. Negative skewness indicates frequent small gains and occasional large losses. Most investors prefer positive skewness.

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$, $\gamma_1 = 0$. For a log-normal distribution, $\gamma_1 > 0$.

### Kurtosis

Kurtosis measures tail heaviness relative to the normal distribution:

$$\gamma_2 = \frac{\mu_4}{\sigma^4} - 3 = \frac{E[(X - \mu)^4]}{\sigma^4} - 3$$

The subtraction of 3 centers kurtosis at 0 for the normal distribution.

**Interpretation**:
- $\gamma_2 > 0$: heavy tails (leptokurtic)
- $\gamma_2 < 0$: light tails (platykurtic)
- $\gamma_2 = 0$: normal tails (mesokurtic)

**Financial interpretation**: High kurtosis indicates frequent extreme returns (both positive and negative). This is common in financial returns and important for risk management.

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$, $\gamma_2 = 0$. Student's $t$-distribution with $\nu$ degrees of freedom has:

$$\gamma_2 = \frac{6}{\nu - 4}$$

for $\nu > 4$, indicating heavier tails than normal.

## Moment Generating Functions

### Moment Generating Function

The moment generating function (MGF) of $X$ is:

$$M_X(t) = E[e^{tX}]$$

defined for $t$ in some neighborhood of 0. If $M_X(t)$ exists, then:

$$E[X^k] = M_X^{(k)}(0) = \left.\frac{d^k}{dt^k} M_X(t)\right|_{t=0}$$

**Properties**:
- $M_X(0) = 1$
- $M_{aX+b}(t) = e^{bt} M_X(at)$
- If $X$ and $Y$ are independent, $M_{X+Y}(t) = M_X(t) M_Y(t)$
- MGF uniquely determines the distribution (if it exists in a neighborhood of 0)

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$:

$$M_X(t) = e^{\mu t + \frac{\sigma^2 t^2}{2}}$$

Differentiating:

$$M_X'(t) = (\mu + \sigma^2 t) e^{\mu t + \frac{\sigma^2 t^2}{2}}$$

so $E[X] = M_X'(0) = \mu$.

### Cumulant Generating Function

The cumulant generating function (CGF) is:

$$K_X(t) = \ln M_X(t)$$

The $k$-th cumulant $\kappa_k$ is:

$$\kappa_k = K_X^{(k)}(0)$$

**Properties**:
- $\kappa_1 = E[X] = \mu$
- $\kappa_2 = \text{Var}(X) = \sigma^2$
- $\kappa_3 = \mu_3$ (related to skewness)
- $\kappa_4 = \mu_4 - 3\sigma^4$ (excess kurtosis)

Cumulants are additive for independent random variables:

$$K_{X+Y}(t) = K_X(t) + K_Y(t)$$

if $X$ and $Y$ are independent.

## Characteristic Functions

### Characteristic Function

The characteristic function of $X$ is:

$$\phi_X(t) = E[e^{itX}] = E[\cos(tX)] + i E[\sin(tX)]$$

where $i = \sqrt{-1}$. Unlike the MGF, the characteristic function always exists.

**Properties**:
- $\phi_X(0) = 1$
- $|\phi_X(t)| \leq 1$
- $\phi_X(-t) = \overline{\phi_X(t)}$ (conjugate symmetry)
- $\phi_{aX+b}(t) = e^{ibt} \phi_X(at)$
- If $X$ and $Y$ are independent, $\phi_{X+Y}(t) = \phi_X(t) \phi_Y(t)$
- Characteristic function uniquely determines the distribution

### Inversion Formula

The distribution can be recovered from the characteristic function:

$$f_X(x) = \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{-itx} \phi_X(t) dt$$

for continuous distributions.

### Fourier Methods

Characteristic functions are Fourier transforms of probability densities. This connection enables:

1. **Convolution**: The density of $X + Y$ (independent) is the convolution of densities, which corresponds to multiplication of characteristic functions.

2. **Central Limit Theorem**: The characteristic function approach provides elegant proofs of limit theorems.

3. **Option Pricing**: Fourier methods are used in option pricing (e.g., Carr-Madan method) when closed-form solutions are unavailable.

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$:

$$\phi_X(t) = e^{i\mu t - \frac{\sigma^2 t^2}{2}}$$

## Inequalities

### Jensen's Inequality

If $\varphi$ is a convex function and $X$ is a random variable, then:

$$\varphi(E[X]) \leq E[\varphi(X)]$$

If $\varphi$ is strictly convex and $X$ is not almost surely constant, the inequality is strict.

**Example**: Since $x^2$ is convex:

$$(E[X])^2 \leq E[X^2]$$

which is equivalent to $\text{Var}(X) \geq 0$.

Since $-\ln(x)$ is convex for $x > 0$:

$$-\ln(E[X]) \leq E[-\ln(X)]$$

or equivalently:

$$E[\ln(X)] \leq \ln(E[X])$$

This shows that the geometric mean is less than or equal to the arithmetic mean.

### Markov's Inequality

For a non-negative random variable $X$ and $a > 0$:

$$\mathbb{P}(X \geq a) \leq \frac{E[X]}{a}$$

**Proof**: $E[X] = E[X \mathbf{1}_{X < a}] + E[X \mathbf{1}_{X \geq a}] \geq E[X \mathbf{1}_{X \geq a}] \geq a \mathbb{P}(X \geq a)$.

### Chebyshev's Inequality

For a random variable $X$ with finite variance and $k > 0$:

$$\mathbb{P}(|X - E[X]| \geq k\sigma) \leq \frac{1}{k^2}$$

where $\sigma = \sqrt{\text{Var}(X)}$.

**Proof**: Apply Markov's inequality to $(X - E[X])^2$:

$$\mathbb{P}(|X - E[X]| \geq k\sigma) = \mathbb{P}((X - E[X])^2 \geq k^2 \sigma^2) \leq \frac{E[(X - E[X])^2]}{k^2 \sigma^2} = \frac{1}{k^2}$$

**Example**: For any distribution with finite variance, at least 75% of values lie within 2 standard deviations of the mean:

$$\mathbb{P}(|X - \mu| < 2\sigma) \geq 1 - \frac{1}{4} = 0.75$$

### Chernoff Bound

For a random variable $X$ and $a \in \mathbb{R}$:

$$\mathbb{P}(X \geq a) \leq \inf_{t > 0} \frac{E[e^{tX}]}{e^{ta}} = \inf_{t > 0} e^{-ta} M_X(t)$$

This is often tighter than Markov's inequality.

**Example**: For $X \sim \text{Normal}(\mu, \sigma^2)$ and $a > \mu$:

$$\mathbb{P}(X \geq a) \leq e^{-\frac{(a-\mu)^2}{2\sigma^2}}$$

by choosing $t = \frac{a-\mu}{\sigma^2}$.

### One-Sided Chebyshev (Cantelli's Inequality)

For a random variable $X$ with finite variance and $a > 0$:

$$\mathbb{P}(X - E[X] \geq a) \leq \frac{\text{Var}(X)}{\text{Var}(X) + a^2}$$

This is tighter than Chebyshev's inequality for one-sided bounds.

## Applications in Finance

### Portfolio Risk

For a portfolio with weights $\mathbf{w}$ and return vector $\mathbf{R}$:

$$E[R_p] = \mathbf{w}^T \boldsymbol{\mu}$$

$$\text{Var}(R_p) = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w}$$

where $\boldsymbol{\mu} = E[\mathbf{R}]$ and $\boldsymbol{\Sigma}$ is the variance-covariance matrix.

### Risk-Adjusted Returns

The Sharpe ratio uses expectation and variance:

$$\text{Sharpe} = \frac{E[R_p] - r_f}{\sigma_p}$$

where $r_f$ is the risk-free rate and $\sigma_p$ is portfolio volatility.

### Higher Moments in Risk Management

Skewness and kurtosis are crucial for:
- **Tail risk**: High kurtosis indicates extreme events
- **Downside risk**: Negative skewness indicates asymmetric downside
- **Option pricing**: Higher moments affect implied volatility smiles
- **Stress testing**: Extreme value theory relies on tail behavior

### Conditional Expectations in Pricing

In risk-neutral pricing, the price of a derivative is:

$$V_0 = e^{-rT} E^Q[V_T | \mathcal{F}_0]$$

where $E^Q$ is expectation under the risk-neutral measure $Q$. The tower property enables dynamic hedging strategies.
