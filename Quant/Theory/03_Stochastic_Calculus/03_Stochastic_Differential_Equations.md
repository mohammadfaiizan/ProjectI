# Stochastic Differential Equations

## Existence and Uniqueness

### Lipschitz Conditions

**Global Lipschitz**: Function $f: \mathbb{R}^n \to \mathbb{R}^n$ satisfies:

$$\|f(x) - f(y)\| \leq K\|x - y\|$$

for all $x, y$ and some constant $K$.

**Linear growth**: 

$$\|f(x)\| \leq K(1 + \|x\|)$$

### Existence and Uniqueness Theorem

For SDE:

$$dX(t) = \mu(t, X(t)) dt + \sigma(t, X(t)) dW(t), \quad X(0) = X_0$$

**Theorem**: If $\mu$ and $\sigma$ satisfy:
1. **Lipschitz condition**: $\|\mu(t,x) - \mu(t,y)\| + \|\sigma(t,x) - \sigma(t,y)\| \leq K\|x-y\|$
2. **Linear growth**: $\|\mu(t,x)\| + \|\sigma(t,x)\| \leq K(1 + \|x\|)$

then there exists unique strong solution $X(t)$ with continuous paths.

**Strong solution**: $X(t)$ is adapted to filtration generated by $W(t)$ and initial condition.

**Uniqueness**: Pathwise uniqueness (two solutions with same initial condition are identical almost surely).

### Weaker Conditions

**Local Lipschitz**: Lipschitz condition holds on compact sets.

**Yamada-Watanabe theorem**: For one-dimensional case, if $\sigma$ is Hölder continuous with exponent $1/2$ and $\mu$ is Lipschitz, then pathwise uniqueness holds.

**Non-explosion**: Additional condition needed to prevent solution from exploding in finite time.

## Linear SDEs

### General Form

$$dX(t) = (A(t)X(t) + a(t)) dt + \sum_{i=1}^{m} (B_i(t)X(t) + b_i(t)) dW_i(t)$$

### Homogeneous Case

**SDE**: $dX(t) = A(t)X(t) dt + B(t)X(t) dW(t)$

**Solution**: 

$$X(t) = X(0) \exp\left(\int_0^t (A(s) - \frac{1}{2}B(s)^2) ds + \int_0^t B(s) dW(s)\right)$$

**Verification**: Apply Itô's lemma to $f(x) = \ln x$.

### Inhomogeneous Case

**SDE**: $dX(t) = (A(t)X(t) + a(t)) dt + (B(t)X(t) + b(t)) dW(t)$

**Solution**: Use variation of constants:

$$X(t) = \Phi(t)\left(X(0) + \int_0^t \Phi(s)^{-1}(a(s) - B(s)b(s)) ds + \int_0^t \Phi(s)^{-1}b(s) dW(s)\right)$$

where $\Phi(t)$ is fundamental solution:

$$d\Phi(t) = A(t)\Phi(t) dt + B(t)\Phi(t) dW(t), \quad \Phi(0) = I$$

### Constant Coefficients

**SDE**: $dX(t) = (AX(t) + a) dt + (BX(t) + b) dW(t)$

**Fundamental solution**: 

$$\Phi(t) = \exp\left((A - \frac{1}{2}B^2)t + BW(t)\right)$$

**Explicit solution**: 

$$X(t) = \Phi(t)\left(X(0) + \int_0^t \Phi(s)^{-1}(a - Bb) ds + \int_0^t \Phi(s)^{-1}b dW(s)\right)$$

## Geometric Brownian Motion Solution

### Derivation

**SDE**: $dS(t) = \mu S(t) dt + \sigma S(t) dW(t)$

**Apply Itô's lemma** to $f(x) = \ln x$:

$$d\ln S(t) = \frac{1}{S(t)} dS(t) - \frac{1}{2S(t)^2} d\langle S \rangle_t$$

$$= \frac{1}{S(t)}(\mu S(t) dt + \sigma S(t) dW(t)) - \frac{1}{2S(t)^2}\sigma^2 S(t)^2 dt$$

$$= (\mu - \frac{\sigma^2}{2}) dt + \sigma dW(t)$$

**Integrate**:

$$\ln S(t) = \ln S(0) + (\mu - \frac{\sigma^2}{2})t + \sigma W(t)$$

**Solution**:

$$S(t) = S(0) \exp\left((\mu - \frac{\sigma^2}{2})t + \sigma W(t)\right)$$

### Properties

**Moments**:
- $E[S(t)] = S(0)e^{\mu t}$
- $\text{Var}(S(t)) = S(0)^2 e^{2\mu t}(e^{\sigma^2 t} - 1)$

**Distribution**: $\ln S(t) \sim \mathcal{N}(\ln S(0) + (\mu - \sigma^2/2)t, \sigma^2 t)$

**Martingale**: Under risk-neutral measure ($\mu = r$), $e^{-rt}S(t)$ is martingale.

## Ornstein-Uhlenbeck Process

### SDE

$$dX(t) = -\theta X(t) dt + \sigma dW(t)$$

where $\theta > 0$ is mean reversion speed.

### Solution Derivation

**Method 1 - Integrating factor**: Multiply by $e^{\theta t}$:

$$d(e^{\theta t}X(t)) = e^{\theta t} dX(t) + \theta e^{\theta t} X(t) dt = \sigma e^{\theta t} dW(t)$$

**Integrate**:

$$e^{\theta t}X(t) = X(0) + \sigma \int_0^t e^{\theta s} dW(s)$$

**Solution**:

$$X(t) = X(0)e^{-\theta t} + \sigma \int_0^t e^{-\theta(t-s)} dW(s)$$

**Method 2 - Variation of constants**: Write as linear SDE with $A = -\theta$, $B = 0$, $a = 0$, $b = \sigma$.

### Properties

**Mean**: $E[X(t)] = X(0)e^{-\theta t} \to 0$ as $t \to \infty$

**Variance**: 

$$\text{Var}(X(t)) = \sigma^2 \int_0^t e^{-2\theta(t-s)} ds = \frac{\sigma^2}{2\theta}(1 - e^{-2\theta t}) \to \frac{\sigma^2}{2\theta}$$

**Covariance**: 

$$\text{Cov}(X(s), X(t)) = \frac{\sigma^2}{2\theta} e^{-\theta|t-s|}$$

**Stationary distribution**: $\mathcal{N}(0, \sigma^2/(2\theta))$

**Mean reversion**: Process reverts to mean 0 at rate $\theta$.

### Applications

**Vasicek interest rate model**: $dr(t) = \kappa(\theta - r(t)) dt + \sigma dW(t)$

**Volatility modeling**: Mean-reverting volatility processes.

**Commodity prices**: Mean-reverting spot prices.

## CIR Process

### SDE

$$dX(t) = \kappa(\theta - X(t)) dt + \sigma\sqrt{X(t)} dW(t)$$

where $\kappa, \theta, \sigma > 0$.

### Properties

**Mean reversion**: Drift pulls $X(t)$ toward $\theta$ at rate $\kappa$.

**Square-root volatility**: Volatility proportional to $\sqrt{X(t)}$.

**Non-negativity**: If $2\kappa\theta \geq \sigma^2$ (Feller condition), $X(t) > 0$ almost surely.

**Stationary distribution**: Gamma distribution with shape $2\kappa\theta/\sigma^2$ and scale $\sigma^2/(2\kappa)$.

### Feller Condition

**Condition**: $2\kappa\theta \geq \sigma^2$

**Interpretation**: Ensures process doesn't hit zero.

**If violated**: Process can hit zero and be absorbed (or reflected).

### Applications

**CIR interest rate model**: $dr(t) = \kappa(\theta - r(t)) dt + \sigma\sqrt{r(t)} dW(t)$

**Heston stochastic volatility**: Variance follows CIR:

$$dV(t) = \kappa(\theta - V(t)) dt + \sigma\sqrt{V(t)} dW_2(t)$$

**Credit risk**: Intensity of default follows CIR.

## Heston Model SDEs

### Stock Price

$$dS(t) = \mu S(t) dt + \sqrt{V(t)} S(t) dW_1(t)$$

**Stochastic volatility**: Volatility $\sqrt{V(t)}$ is random.

### Variance Process

$$dV(t) = \kappa(\theta - V(t)) dt + \sigma\sqrt{V(t)} dW_2(t)$$

**CIR process**: Variance follows square-root process.

### Correlation

$$d\langle W_1, W_2 \rangle_t = \rho dt$$

**Leverage effect**: Negative correlation ($\rho < 0$) captures volatility clustering.

### Properties

**Volatility smile**: Model generates implied volatility smile/skew.

**Mean reversion**: Volatility reverts to long-term level $\theta$.

**Feller condition**: $2\kappa\theta \geq \sigma^2$ ensures $V(t) > 0$.

### Option Pricing

**Characteristic function**: Available in closed form:

$$\phi(u, t) = E[\exp(iu \ln S(t))]$$

**Fourier inversion**: Use Carr-Madan method to price options.

**Calibration**: Fit model parameters to market option prices.

## Numerical Methods

### Euler-Maruyama Scheme

**Discretization**: For $dX(t) = \mu(t, X(t)) dt + \sigma(t, X(t)) dW(t)$:

$$X_{n+1} = X_n + \mu(t_n, X_n)\Delta t + \sigma(t_n, X_n)\Delta W_n$$

where $\Delta W_n = W(t_{n+1}) - W(t_n) \sim \mathcal{N}(0, \Delta t)$.

**Convergence**: Strong order 1/2, weak order 1.

**Error**: $E[|X(T) - X_N|] = O(\sqrt{\Delta t})$

### Milstein Scheme

**Discretization**:

$$X_{n+1} = X_n + \mu(t_n, X_n)\Delta t + \sigma(t_n, X_n)\Delta W_n + \frac{1}{2}\sigma(t_n, X_n)\sigma'(t_n, X_n)((\Delta W_n)^2 - \Delta t)$$

**Convergence**: Strong order 1.

**Requirement**: Need derivative $\sigma'$ (not always available).

**Error**: $E[|X(T) - X_N|] = O(\Delta t)$

### Higher-Order Schemes

**Runge-Kutta methods**: Extend deterministic RK methods to SDEs.

**Taylor schemes**: Expand using Itô-Taylor expansion.

**Implicit schemes**: For stiff SDEs (e.g., mean-reverting processes).

### Applications

**Monte Carlo simulation**: Generate sample paths for option pricing.

**Risk management**: Simulate portfolio values under stress scenarios.

**Calibration**: Evaluate model prices for parameter estimation.

## Applications in Finance

### Interest Rate Models

**Vasicek**: $dr(t) = \kappa(\theta - r(t)) dt + \sigma dW(t)$

**CIR**: $dr(t) = \kappa(\theta - r(t)) dt + \sigma\sqrt{r(t)} dW(t)$

**Hull-White**: $dr(t) = (\theta(t) - \kappa r(t)) dt + \sigma dW(t)$

**Bond pricing**: Solve PDE or use affine structure.

### Stochastic Volatility

**Heston**: Variance follows CIR process.

**SABR**: $dS = \sigma S^\beta dW_1$, $d\sigma = \alpha\sigma dW_2$ with correlation.

**3/2 model**: $dV = \kappa V(\theta - V) dt + \sigma V^{3/2} dW$.

### Credit Risk

**Intensity models**: Default intensity follows SDE:

$$d\lambda(t) = \kappa(\theta - \lambda(t)) dt + \sigma\sqrt{\lambda(t)} dW(t)$$

**First passage**: Default when firm value hits barrier.

**Reduced-form**: Default time $\tau$ with intensity $\lambda(t)$.

### Commodity Modeling

**Mean-reverting spot**: $dS(t) = \kappa(\theta - S(t)) dt + \sigma dW(t)$

**Convenience yield**: Additional factor in cost of carry model.

**Seasonality**: Add deterministic seasonal component.

### Energy Markets

**Electricity prices**: Jump-diffusion with mean reversion.

**Gas prices**: Stochastic volatility with spikes.

**Oil prices**: Geometric Brownian motion with regime switching.
