# Transformers And Attention

## Q1: Explain the self-attention mechanism and its core computation.

**A1:** Self-attention allows each position in a sequence to attend to all other positions, computing relationships between elements within the same sequence. The mechanism uses three learned matrices: Query (Q), Key (K), and Value (V), all derived from the input embeddings. For each position, attention scores are computed as the dot product of queries with keys, measuring similarity between positions. These scores are scaled and passed through softmax to create attention weights, which are then used to compute a weighted sum of value vectors. This enables the model to dynamically focus on relevant parts of the input when processing each position, capturing dependencies regardless of distance. Self-attention provides direct connections between all positions, solving the sequential bottleneck of RNNs.

## Q2: What is scaled dot-product attention and why is scaling necessary?

**A2:** Scaled dot-product attention computes attention scores as QK^T divided by the square root of the key dimension (sqrt(d_k)). The scaling factor prevents the dot products from growing too large in magnitude, which would push softmax outputs into regions with extremely small gradients. Without scaling, when d_k is large, the dot products can have large variance, causing softmax to saturate and making gradients vanish during training. Dividing by sqrt(d_k) normalizes the variance of the dot products, keeping them in a range where softmax can produce well-distributed attention weights. This scaling is crucial for stable training and effective learning in transformer models, especially as model dimensions increase.

## Q3: How does multi-head attention work and what are its advantages?

**A3:** Multi-head attention runs multiple parallel attention mechanisms, called heads, each with its own learned Q, K, and V projection matrices. Each head can learn to attend to different aspects of the relationships between positions, such as syntactic, semantic, or positional patterns. The outputs from all heads are concatenated and projected through a final linear layer to produce the multi-head attention output. This parallel processing allows the model to capture diverse types of relationships simultaneously, rather than forcing a single attention mechanism to learn all patterns. Multi-head attention significantly improves model capacity and performance, enabling richer representations by attending to information from different representation subspaces at different positions.

## Q4: Compare sinusoidal and learned positional encodings in transformers.

**A4:** Sinusoidal positional encodings use fixed mathematical functions (sine and cosine) with different frequencies to encode position information, added directly to input embeddings. They're deterministic, don't require learning, and can theoretically generalize to sequences longer than those seen during training. Learned positional encodings are learned parameters that the model optimizes during training, stored as an embedding table where each position has a learned vector. Learned encodings can adapt to the specific task and data distribution but are limited to the maximum sequence length seen during training. Sinusoidal encodings provide better extrapolation to longer sequences, while learned encodings often perform slightly better on in-distribution data. Modern models often use learned encodings for simplicity and comparable performance within training length limits.

## Q5: Describe the encoder-decoder transformer architecture and its components.

**A5:** The transformer encoder-decoder consists of an encoder stack that processes the input sequence and a decoder stack that generates the output sequence. The encoder contains multiple identical layers, each with multi-head self-attention and a feed-forward network, both followed by residual connections and layer normalization. The decoder has similar structure but includes an additional cross-attention layer that attends to encoder outputs, allowing it to incorporate input information when generating outputs. The decoder uses masked self-attention to prevent positions from attending to future positions, ensuring autoregressive generation. Both encoder and decoder use positional encodings to inject sequence order information. This architecture enables parallel training of the encoder while maintaining sequential generation in the decoder.

## Q6: What is layer normalization and how is it used in transformers?

**A6:** Layer normalization normalizes activations across the features for each individual sample, computing mean and variance over the feature dimension rather than the batch dimension like batch normalization. In transformers, layer normalization is applied after attention and feed-forward layers, typically using pre-norm or post-norm configurations. Pre-norm applies normalization before the sublayer, while post-norm applies it after, with pre-norm generally providing more stable training. Layer normalization helps stabilize training by reducing internal covariate shift and allows for more consistent gradient flow through deep networks. It's particularly important in transformers because it enables training very deep models and helps with the residual connections that are fundamental to transformer architecture.

## Q7: Explain the feed-forward network component in transformer blocks.

**A7:** The feed-forward network in each transformer block consists of two linear transformations with a ReLU activation in between, typically expanding the dimension by a factor of 4 before projecting back down. This network is applied independently and identically to each position, meaning it processes each token's representation separately. The expansion allows the network to learn complex non-linear transformations of the attended representations. Despite being position-wise, the feed-forward network works in conjunction with attention to enable the model to process and transform information. The combination of self-attention (which mixes information across positions) and feed-forward networks (which processes information at each position) creates a powerful architecture for sequence modeling.

## Q8: What is masked self-attention and why is it necessary in the decoder?

**A8:** Masked self-attention prevents the decoder from attending to future positions by setting attention scores to negative infinity (which become zero after softmax) for positions beyond the current token. This masking ensures that during training and inference, the model can only use information from previously generated tokens when predicting the next token, maintaining the autoregressive property. Without masking, the decoder could cheat by looking at future tokens, making training and inference inconsistent. The mask is typically implemented as an upper triangular matrix of negative infinities, applied before the softmax operation. This masking is crucial for language modeling and sequence generation tasks where the model must generate outputs sequentially without access to future information.

## Q9: How does cross-attention differ from self-attention in transformers?

**A9:** Cross-attention allows the decoder to attend to encoder outputs, using queries from the decoder and keys and values from the encoder. This creates a connection between the input and output sequences, enabling the decoder to incorporate relevant information from the input when generating each output token. Unlike self-attention where Q, K, and V all come from the same sequence, cross-attention mixes information from different sequences. The attention mechanism computes which parts of the input sequence are most relevant for generating each output position, similar to alignment in sequence-to-sequence models. Cross-attention is essential for tasks like machine translation, summarization, and question answering where the output must be conditioned on specific input information.

## Q10: Explain the intuition behind query, key, and value in attention mechanisms.

**A10:** The query represents "what am I looking for" - it's the current position's request for information. The key represents "what I can offer" - it describes what information each position contains. The value represents "what I actually provide" - it's the actual content that gets retrieved when attention is paid to that position. The attention mechanism computes similarity between queries and keys to determine how much attention to pay, then uses those weights to combine the values. This is analogous to a database lookup: queries search through keys to find matches, then retrieve the corresponding values. The learned transformations allow the model to learn what aspects to match on and what information to extract, making attention a flexible mechanism for information retrieval and combination.

## Q11: Why do we scale attention scores by sqrt(d_k) instead of just d_k?

**A11:** Scaling by sqrt(d_k) rather than d_k maintains the variance of the dot products at approximately 1, assuming Q and K have unit variance. If we assume Q and K are independent random variables with mean 0 and variance 1, the dot product has variance d_k. Dividing by sqrt(d_k) normalizes this variance to 1, keeping the dot products in a range where softmax produces well-distributed probabilities. Using sqrt(d_k) rather than d_k prevents over-scaling, which would make the attention weights too uniform and reduce the model's ability to focus on specific positions. The square root scaling is the mathematically correct normalization factor for maintaining unit variance in the attention scores.

## Q12: How do transformers enable parallelization compared to RNNs?

**A12:** Transformers process all positions in a sequence simultaneously, computing attention for all positions in parallel, unlike RNNs which must process sequences sequentially. During training, the entire sequence can be processed in one forward pass, making full use of parallel hardware like GPUs. RNNs require sequential computation where each time step depends on the previous one, creating a dependency chain that prevents parallelization. Transformers achieve this through self-attention, which computes relationships between all pairs of positions independently, then combines them. This parallelization dramatically speeds up training and allows transformers to process much longer sequences efficiently. The trade-off is that transformers require quadratic memory with sequence length due to storing attention matrices, while RNNs have linear memory requirements.

## Q13: Compare pre-norm and post-norm transformer architectures.

**A13:** Pre-norm applies layer normalization before the attention or feed-forward sublayer, while post-norm applies it after the sublayer and residual connection. Pre-norm architectures generally train more stably, especially for deeper networks, because normalization happens before potentially unstable operations. Post-norm was used in the original transformer paper but can suffer from gradient issues in very deep networks. Pre-norm allows gradients to flow more directly through residual connections since normalization happens earlier in the path. However, post-norm can sometimes achieve slightly better final performance with careful initialization and training. Modern transformer variants like GPT and many recent models prefer pre-norm for its training stability, though both approaches are viable depending on the specific architecture and training setup.

## Q14: What is relative positional encoding and how does RoPE work?

**A14:** Relative positional encoding encodes the relative distance between positions rather than absolute positions, which can generalize better to longer sequences. Rotary Position Embedding (RoPE) applies rotations to query and key vectors based on their positions, encoding relative position information directly in the attention computation. RoPE multiplies queries and keys by rotation matrices that depend on their positions, creating position-dependent phase shifts. This approach naturally encodes relative positions because the dot product between rotated vectors depends on their relative position difference. RoPE has shown strong performance and is used in models like LLaMA, providing better extrapolation to longer sequences than absolute positional encodings. It integrates position information more naturally into the attention mechanism.

## Q15: Explain ALiBi (Attention with Linear Biases) positional encoding.

**A15:** ALiBi adds a linear bias to attention scores based on the distance between query and key positions, with the bias magnitude proportional to the distance. The bias is subtracted from attention scores before softmax, penalizing attention to distant positions. Unlike learned or sinusoidal encodings, ALiBi doesn't add positional information to embeddings but modifies attention directly. The slope of the linear bias is a hyperparameter that can be tuned per attention head. ALiBi has shown excellent extrapolation to sequences much longer than those seen during training, making it valuable for long-context applications. It's simpler than RoPE and doesn't require modifying the attention computation structure, just adding biases to scores.

## Q16: What are sparse attention patterns and why are they used?

**A16:** Sparse attention patterns limit attention to a subset of positions rather than all positions, reducing the quadratic complexity of full attention. Common patterns include local attention (only nearby positions), strided attention (every k-th position), or learned patterns where the model learns which positions to attend to. Sparse attention makes transformers scalable to much longer sequences by reducing memory and computation from O(n²) to O(n√n) or O(n log n) depending on the pattern. However, sparse patterns may miss important long-range dependencies that full attention would capture. Techniques like Longformer and BigBird use sparse attention to handle sequences of thousands or tens of thousands of tokens while maintaining reasonable computational costs.

## Q17: What is linear attention and how does it reduce computational complexity?

**A17:** Linear attention reformulates the attention computation to avoid explicitly computing the n×n attention matrix, reducing complexity from O(n²) to O(n). Instead of computing softmax(QK^T)V, linear attention uses the associativity of matrix multiplication to compute the equivalent result as (QK^T)V = Q(K^T V), or uses kernel-based approximations. Some methods replace softmax with other kernels that allow factorization, while others use low-rank approximations of the attention matrix. Linear attention enables processing much longer sequences but may sacrifice some expressiveness compared to standard attention. The trade-off between efficiency and performance depends on the specific linearization method and the task requirements.

## Q18: Explain Flash Attention and its optimization strategy.

**A18:** Flash Attention is a memory-efficient attention algorithm that computes attention without storing the full attention matrix in memory. It uses tiling to break the computation into blocks that fit in fast SRAM, recomputing attention scores on-the-fly during the backward pass rather than storing them. This reduces memory usage from O(n²) to O(n) while maintaining exact attention computation, not an approximation. Flash Attention achieves significant speedups on GPUs by reducing memory reads and writes, which are often the bottleneck in attention computation. It's particularly beneficial for training large models on long sequences where memory constraints would otherwise limit batch size or sequence length. The algorithm maintains numerical stability and produces identical results to standard attention.

## Q19: What is KV-cache and how does it speed up transformer inference?

**A19:** KV-cache stores the key and value vectors computed during previous decoding steps, avoiding recomputation of these expensive operations. During autoregressive generation, queries change at each step, but keys and values for previous tokens remain the same. By caching K and V from previous steps, the model only needs to compute keys and values for the new token, then concatenate with cached values. This reduces computation from O(n²) per step to O(n), dramatically speeding up generation. KV-cache is essential for efficient inference in language models, reducing latency and enabling real-time applications. The trade-off is increased memory usage proportional to sequence length, but this is typically acceptable during inference where batch sizes are smaller.

## Q20: How does mixture of experts work in transformer architectures?

**A20:** Mixture of experts (MoE) replaces the feed-forward network in transformer blocks with multiple expert networks and a routing mechanism that selects which experts process each token. Only a subset of experts are activated for each token, reducing computation while maintaining model capacity. The routing network learns to assign tokens to appropriate experts, potentially allowing specialization where different experts handle different types of patterns. MoE enables scaling model parameters without proportionally increasing computation, as only a few experts are active per token. This approach has been used in models like Switch Transformers and GLaM to create models with trillions of parameters while keeping training and inference costs manageable. The challenge is balancing expert utilization and ensuring all experts receive sufficient training.
