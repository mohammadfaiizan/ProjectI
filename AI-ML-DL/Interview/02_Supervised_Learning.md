# Supervised Learning

## Q1: Explain linear regression and its key assumptions.

**A1:** Linear regression models the relationship between a dependent variable and one or more independent variables using a linear equation. The model assumes linearity between features and target, independence of observations, homoscedasticity where error variance is constant, normality of error terms, and no perfect multicollinearity among features. The goal is to find coefficients that minimize the sum of squared differences between predicted and actual values. Simple linear regression uses one feature, while multiple linear regression uses multiple features. The model is interpretable, computationally efficient, and serves as a baseline for more complex methods. Violations of assumptions can lead to biased estimates and poor predictions.

## Q2: What is the cost function in linear regression and how is it optimized?

**A2:** The cost function in linear regression is typically the Mean Squared Error, which calculates the average of squared differences between predicted and actual values. Mathematically, MSE equals the sum of (y_predicted - y_actual)² divided by the number of samples. This function is convex, ensuring a global minimum exists. Optimization can be done analytically using the normal equation, which directly computes optimal coefficients using matrix operations: θ = (X^T X)^(-1) X^T y. Alternatively, iterative optimization methods like gradient descent are used, especially for large datasets where matrix inversion is expensive. The normal equation is faster for small datasets but becomes computationally prohibitive for large feature spaces.

## Q3: What is the normal equation in linear regression?

**A3:** The normal equation provides an analytical solution to find the optimal parameters for linear regression without iterative optimization. It directly computes the coefficients that minimize the cost function using the formula θ = (X^T X)^(-1) X^T y, where X is the feature matrix and y is the target vector. This method solves the least squares problem exactly in one step. It's computationally efficient for small to medium datasets but requires matrix inversion, which has O(n³) complexity. The normal equation doesn't require feature scaling and doesn't need a learning rate. However, it fails when X^T X is singular or non-invertible, which can occur with redundant features or when features exceed samples.

## Q4: Explain logistic regression and the sigmoid function.

**A4:** Logistic regression is a classification algorithm that models the probability of a binary outcome using the logistic sigmoid function. The sigmoid function transforms linear combinations of features into probabilities between 0 and 1: σ(z) = 1 / (1 + e^(-z)). This S-shaped curve ensures outputs are bounded and interpretable as probabilities. Logistic regression estimates coefficients using maximum likelihood estimation rather than least squares. The decision boundary is linear, separating classes based on a probability threshold, typically 0.5. Despite its name, it's a classification algorithm, not regression. It provides probabilistic outputs, handles non-linear relationships through feature engineering, and serves as a foundation for neural networks.

## Q5: How does logistic regression handle multiclass classification?

**A5:** Logistic regression extends to multiclass problems through two main approaches. One-vs-Rest trains multiple binary classifiers, one for each class against all others, and selects the class with highest probability. One-vs-One trains classifiers for each pair of classes and uses voting. Multinomial logistic regression, or softmax regression, directly models multiclass probabilities using the softmax function, which generalizes sigmoid to multiple classes. Softmax ensures probabilities sum to one across all classes. The multinomial approach is more principled and efficient, learning a single model that directly handles all classes simultaneously. It uses cross-entropy loss and provides calibrated probability estimates for each class.

## Q6: What are the different variants of gradient descent?

**A6:** Batch gradient descent computes gradients using the entire training dataset for each update, providing stable convergence but being computationally expensive for large datasets. Stochastic gradient descent uses one random sample per iteration, making it fast and memory-efficient but with noisy, high-variance updates that may not converge smoothly. Mini-batch gradient descent strikes a balance by using small random subsets of data, typically 32-256 samples, combining efficiency with stability. Adaptive methods like Adam, RMSprop, and AdaGrad adjust learning rates automatically. Batch GD guarantees convergence to global minimum for convex functions but is slow. SGD converges faster but may oscillate. Mini-batch is the most commonly used in practice.

## Q7: Explain K-Nearest Neighbors algorithm and distance metrics.

**A7:** K-Nearest Neighbors is an instance-based, non-parametric algorithm that classifies or predicts by finding the K most similar training examples to a query point. For classification, it uses majority voting among K neighbors; for regression, it averages their target values. Common distance metrics include Euclidean distance for continuous features, Manhattan distance for grid-like data, Minkowski distance as a generalization, Hamming distance for categorical data, and cosine similarity for high-dimensional sparse data. The choice of K balances bias and variance: small K leads to low bias but high variance, while large K increases bias but reduces variance. KNN is simple, requires no training, but is computationally expensive for prediction and sensitive to irrelevant features.

## Q8: How do you choose the optimal value of K in KNN?

**A8:** Choosing K involves balancing model complexity and generalization. Small K values make the model sensitive to noise and local variations, leading to overfitting. Large K values smooth out decision boundaries but may underfit by ignoring local patterns. Common approaches include using cross-validation to evaluate different K values and selecting the one with best validation performance. The square root of the number of training samples is a heuristic starting point. Odd K values prevent ties in binary classification. Elbow method plots error against K to find the point where error stabilizes. Domain knowledge and computational constraints also influence the choice. Typically, K values between 3 and 10 work well for many problems.

## Q9: Explain Naive Bayes and its independence assumption.

**A9:** Naive Bayes is a probabilistic classifier based on Bayes' theorem that assumes feature independence given the class label. Despite this naive assumption rarely holding in practice, the algorithm often performs well. It calculates posterior probability P(class|features) using prior probability P(class) and likelihood P(features|class), with the independence assumption allowing simple multiplication of individual feature probabilities. Variants include Gaussian Naive Bayes for continuous features assuming normal distributions, Multinomial Naive Bayes for count data, and Bernoulli Naive Bayes for binary features. The algorithm is fast, requires little training data, handles high-dimensional data well, and works surprisingly effectively even when independence assumption is violated due to its focus on classification rather than accurate probability estimation.

## Q10: What are the different types of Naive Bayes classifiers?

**A10:** Gaussian Naive Bayes assumes continuous features follow Gaussian distributions, estimating mean and variance for each feature-class combination. It's suitable for normally distributed continuous data. Multinomial Naive Bayes models feature counts using multinomial distributions, ideal for discrete count data like word frequencies in text classification. Bernoulli Naive Bayes models binary features using Bernoulli distributions, appropriate for binary feature vectors. Complement Naive Bayes addresses imbalanced classes by using complement class statistics. Each variant makes distributional assumptions matching different data types. The choice depends on feature characteristics: Gaussian for continuous, Multinomial for counts, and Bernoulli for binary features. All share the naive independence assumption but differ in how they model feature distributions.

## Q11: Explain polynomial regression and when to use it.

**A11:** Polynomial regression extends linear regression by adding polynomial terms of features, allowing the model to capture nonlinear relationships while remaining linear in parameters. It transforms features by creating powers and interactions, such as x², x³, or x₁x₂. The model can fit curved relationships but remains interpretable through polynomial coefficients. It's useful when relationships are nonlinear but smooth, and when domain knowledge suggests polynomial relationships. However, high-degree polynomials can overfit, especially with limited data. Regularization techniques like Ridge or Lasso help control complexity. Feature scaling becomes important due to large value differences between polynomial terms. Cross-validation helps select appropriate polynomial degree.

## Q12: Compare Ridge and Lasso regularization.

**A12:** Ridge regression adds L2 penalty (sum of squared coefficients) to the cost function, shrinking coefficients toward zero without eliminating them. It's effective for multicollinearity and prevents overfitting while keeping all features. Lasso regression adds L1 penalty (sum of absolute coefficients), which can drive coefficients exactly to zero, performing automatic feature selection. Ridge is better when many features are relevant, while Lasso excels when only few features matter. Ridge handles correlated features better, while Lasso may arbitrarily select one from a correlated group. Elastic Net combines both penalties, balancing their benefits. Ridge's solution is unique and smooth, while Lasso can have multiple solutions and creates sparse models. The choice depends on whether feature selection is desired.

## Q13: What is Elastic Net regularization?

**A13:** Elastic Net combines L1 (Lasso) and L2 (Ridge) regularization penalties, providing a balance between feature selection and coefficient shrinkage. The cost function includes both the sum of absolute coefficients and sum of squared coefficients, weighted by mixing parameter α. When α=1, it's pure Lasso; when α=0, it's pure Ridge. Elastic Net inherits Lasso's ability to perform feature selection while maintaining Ridge's stability with correlated features. It's particularly useful when the number of features exceeds samples or when features are highly correlated. The method requires tuning both the regularization strength λ and mixing parameter α. It often outperforms pure Lasso or Ridge, especially in high-dimensional settings with correlated predictors.

## Q14: Explain softmax regression for multiclass classification.

**A14:** Softmax regression, or multinomial logistic regression, extends logistic regression to multiple classes by using the softmax function to convert raw scores into probability distributions. The softmax function exponentiates each class score and normalizes by the sum of all exponentials, ensuring probabilities sum to one. It learns a weight matrix where each row corresponds to a class, and predictions are made by selecting the class with highest probability. The loss function is cross-entropy, measuring the difference between predicted and true probability distributions. Softmax provides calibrated probabilities for all classes simultaneously, unlike one-vs-rest approaches. It's the standard output layer for neural network multiclass classification and is trained using gradient descent with backpropagation.

## Q15: What is the perceptron algorithm?

**A15:** The perceptron is a binary linear classifier that learns a decision boundary by iteratively updating weights based on misclassified examples. It starts with random weights and adjusts them whenever a training example is misclassified, moving the decision boundary in the direction that would correctly classify that example. The update rule adds the feature vector to weights if the example is positive and misclassified, or subtracts it if negative and misclassified. The perceptron convergence theorem guarantees convergence if data is linearly separable, but it may not converge for non-separable data. It's a simple neural network with a single layer and step activation function. Modern variants use learning rates and handle non-separable data through modifications like the pocket algorithm.

## Q16: Explain Maximum Likelihood Estimation in the context of supervised learning.

**A16:** Maximum Likelihood Estimation finds parameter values that maximize the probability of observing the training data given the model. It assumes data points are independent and identically distributed, then maximizes the likelihood function, which is the product of individual data point probabilities. For linear regression with Gaussian errors, MLE is equivalent to minimizing mean squared error. For logistic regression, MLE maximizes the likelihood of observed class labels given features. MLE provides a principled framework for parameter estimation with desirable properties like consistency and asymptotic normality. It's often implemented by minimizing negative log-likelihood, which is equivalent but numerically more stable. MLE assumes a specific data distribution and may overfit with complex models.

## Q17: What is MAP estimation and how does it differ from MLE?

**A17:** Maximum A Posteriori estimation incorporates prior knowledge about parameters through Bayes' theorem, finding parameters that maximize the posterior distribution P(parameters|data). Unlike MLE which only considers data likelihood, MAP multiplies likelihood by prior distribution, effectively regularizing the solution. The prior encodes domain knowledge or assumptions about reasonable parameter values. MAP estimation is equivalent to MLE when using uniform priors, but informative priors bias estimates toward prior expectations. It provides a Bayesian approach to parameter estimation while being computationally simpler than full Bayesian inference. MAP naturally handles overfitting by penalizing extreme parameter values. Common priors include Gaussian priors leading to Ridge-like regularization or Laplacian priors leading to Lasso-like sparsity.

## Q18: Explain Bayesian linear regression.

**A18:** Bayesian linear regression treats model parameters as random variables with probability distributions rather than fixed values. It starts with prior distributions over parameters, typically Gaussian, representing beliefs before seeing data. Upon observing data, it updates beliefs using Bayes' theorem to obtain posterior distributions. This provides uncertainty estimates for predictions, not just point estimates. Predictions are made by integrating over the posterior distribution, naturally accounting for parameter uncertainty. The approach handles overfitting through the prior and provides principled uncertainty quantification. Computational methods include analytical solutions for conjugate priors or Markov Chain Monte Carlo for complex cases. Bayesian regression is more interpretable and robust but computationally more expensive than frequentist approaches.

## Q19: Compare different cost functions: MSE, MAE, Huber, and cross-entropy.

**A19:** Mean Squared Error penalizes large errors quadratically, making it sensitive to outliers but providing smooth gradients. It assumes Gaussian error distribution and is optimal for regression under this assumption. Mean Absolute Error uses linear penalties, making it robust to outliers but with non-smooth gradients at zero. It assumes Laplacian error distribution. Huber loss combines both, quadratic for small errors and linear for large errors, balancing smoothness and robustness. Cross-entropy is used for classification, measuring the difference between predicted and true probability distributions. It's equivalent to negative log-likelihood for classification and provides strong gradients when predictions are wrong. MSE works well for regression with normal errors, MAE for robustness, Huber for balanced approach, and cross-entropy for probabilistic classification.

## Q20: How do you interpret learning curves to diagnose model issues?

**A20:** Learning curves plot training and validation performance against training set size or number of iterations. If both curves plateau at similar high error, the model has high bias and underfitting, suggesting need for more complexity or features. If training error is low but validation error is high with a large gap, the model has high variance and overfitting, indicating need for regularization or more data. If validation error decreases as training size increases, more data would help. Convergence issues show as erratic or non-converging curves. The ideal curve shows both errors decreasing and converging to similar values. Learning curves help diagnose bias-variance tradeoff, determine if more data would help, assess convergence, and guide model selection and hyperparameter tuning decisions.
