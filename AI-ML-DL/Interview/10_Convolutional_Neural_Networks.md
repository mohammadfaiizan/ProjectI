# Convolutional Neural Networks

## Q1: Explain the convolution operation in CNNs.

**A1:** Convolution applies a filter (kernel) to an input by sliding the filter across the input and computing element-wise multiplications followed by summation at each position. The filter detects local patterns like edges, textures, or shapes by learning appropriate weights through training. Each filter produces a feature map that highlights where the pattern appears in the input. Convolution is parameter-efficient: a single filter is shared across all spatial locations, dramatically reducing parameters compared to fully connected layers. The operation preserves spatial relationships in the input, making it ideal for image data where nearby pixels are related. Multiple filters are used to detect different patterns, with each filter learning to recognize distinct features. Convolution forms the foundation of CNNs, enabling them to learn hierarchical feature representations from low-level edges to high-level objects.

## Q2: What are stride and padding in convolutional layers?

**A2:** Stride controls how many pixels the filter moves between applications: stride=1 moves one pixel at a time, stride=2 moves two pixels, reducing output spatial dimensions. Larger strides reduce computational cost and output size but may lose fine-grained spatial information. Padding adds zeros (or other values) around the input border to control output size: 'valid' padding uses no padding (output shrinks), 'same' padding adds enough padding to maintain input size. Padding prevents information loss at borders and allows filters to process edge pixels properly. The relationship between input size, filter size, stride, and padding determines output dimensions: output = (input + 2×padding - filter_size)/stride + 1. Proper padding and stride selection balances between preserving spatial information, controlling model size, and computational efficiency. These hyperparameters significantly affect network architecture and performance.

## Q3: Explain pooling layers: max, average, and global pooling.

**A3:** Pooling layers reduce spatial dimensions while retaining important information, providing translation invariance and reducing computational cost. Max pooling selects the maximum value in each pooling window, preserving the strongest activation and providing robustness to small translations. Average pooling computes the mean value in each window, providing smoother, less aggressive downsampling. Global pooling (max or average) reduces entire feature maps to single values, often used before classification layers to create fixed-size representations regardless of input size. Pooling layers typically use 2×2 windows with stride 2, halving spatial dimensions. They help control overfitting by reducing parameters and provide a form of regularization. Max pooling is more common as it preserves strong features and provides better gradient flow, while average pooling is sometimes used in specific architectures. Pooling enables CNNs to build hierarchical representations with increasing levels of abstraction.

## Q4: What are 1×1 convolutions and why are they useful?

**A4:** 1×1 convolutions apply filters of size 1×1 across all channels, effectively performing cross-channel linear combinations without changing spatial dimensions. They act as learnable linear transformations that can increase or decrease the number of channels, providing dimensionality reduction or expansion. 1×1 convolutions are computationally cheap but enable complex channel interactions, allowing the network to learn which feature combinations are useful. They're used in bottleneck architectures to reduce parameters before expensive 3×3 convolutions, then restore channels afterward. 1×1 convolutions also enable non-linearity when followed by activation functions, adding model capacity with minimal cost. In networks like Inception and ResNet, they provide efficient channel mixing and dimensionality control. Despite their simplicity, 1×1 convolutions are powerful tools for building efficient, expressive CNN architectures.

## Q5: Explain depthwise separable convolutions.

**A5:** Depthwise separable convolution splits standard convolution into two operations: depthwise convolution applies a single filter per input channel independently, then pointwise convolution (1×1) mixes channels. This factorization dramatically reduces parameters and computation: standard convolution requires filters × input_channels × output_channels parameters, while separable convolution needs filters + input_channels × output_channels. The reduction is approximately 1/output_channels + 1/filter_size, providing 8-10x reduction for typical configurations. Depthwise separable convolutions maintain representational capacity while being much more efficient, enabling mobile and embedded applications. They form the basis of architectures like MobileNet and Xception, which achieve good performance with far fewer parameters than standard CNNs. The approach demonstrates that standard convolution can be factorized without significant accuracy loss, making deep learning more accessible on resource-constrained devices.

## Q6: What is the receptive field in CNNs?

**A6:** The receptive field is the region of the input image that affects a particular neuron's activation, representing how much of the input each neuron "sees." Early layers have small receptive fields detecting local patterns like edges, while deeper layers have larger receptive fields capturing more global structures. Receptive field size grows with network depth and depends on filter size, stride, and padding. Larger receptive fields enable neurons to integrate information over wider areas, necessary for recognizing complex objects. However, very deep networks may have receptive fields larger than the image, which is often unnecessary. Understanding receptive fields helps design architectures: ensuring sufficient size for the task while avoiding excessive depth. Techniques like dilated convolutions can increase receptive fields without adding layers or parameters, providing efficient ways to capture long-range dependencies.

## Q7: Explain feature maps and filters in CNNs.

**A7:** Feature maps are the outputs of convolutional layers, representing where and how strongly detected patterns appear in the input. Each filter produces one feature map by convolving across the input, with high activations indicating pattern presence. Multiple filters create multiple feature maps, each detecting different patterns like vertical edges, horizontal edges, or textures. As networks deepen, feature maps become more abstract: early layers detect simple patterns, later layers detect complex objects. Filters are the learned weights that define what patterns each feature map detects, trained through backpropagation to recognize useful features for the task. The number of filters determines network capacity: more filters allow detecting more patterns but increase parameters and computation. Feature maps and filters work together to build hierarchical representations, transforming raw pixels into increasingly abstract and task-relevant features.

## Q8: Describe the LeNet architecture and its significance.

**A8:** LeNet, developed by Yann LeCun in the 1990s, was one of the first successful CNN architectures for handwritten digit recognition. It consists of convolutional layers followed by subsampling (pooling), then fully connected layers for classification. LeNet demonstrated that CNNs could learn useful features automatically from data, rather than requiring hand-engineered features. The architecture established the basic CNN pattern: alternating convolution and pooling layers to build hierarchical features, then classification layers. Although simple by modern standards, LeNet proved the viability of convolutional architectures and gradient-based learning. It successfully applied backpropagation to convolutional networks, showing that end-to-end training was feasible. LeNet's success on MNIST digit recognition laid the foundation for modern deep learning in computer vision, establishing principles that remain relevant today.

## Q9: What were the key innovations in AlexNet?

**A9:** AlexNet, winner of ImageNet 2012, popularized deep CNNs and introduced several important techniques. It used ReLU activation instead of tanh/sigmoid, enabling training of deeper networks by addressing vanishing gradients. AlexNet employed dropout for regularization, preventing overfitting in the large fully connected layers. It used data augmentation (cropping, flipping) to increase effective dataset size and improve generalization. The network was trained on GPUs, demonstrating the importance of parallel computation for deep learning. AlexNet used local response normalization (now less common) and overlapping pooling. The architecture's success on ImageNet, reducing error from 26% to 15%, sparked the deep learning revolution. AlexNet showed that deeper networks with proper techniques could achieve dramatically better performance, establishing CNNs as the dominant approach for computer vision.

## Q10: Explain VGG's design philosophy.

**A10:** VGG demonstrated that network depth is crucial for performance, using very small 3×3 filters stacked to create deeper networks. Instead of large filters, VGG uses multiple 3×3 convolutions to achieve the same receptive field with fewer parameters and more non-linearities. The architecture follows a simple, uniform design: blocks of convolutional layers with increasing filters, periodic max pooling for downsampling, then fully connected layers. VGG showed that systematic depth increases improve performance, though training becomes more challenging. The uniform structure makes VGG easy to understand and modify, though it's parameter-heavy due to large fully connected layers. VGG's success validated that depth matters more than complex architectural tricks, influencing later architectures. Despite being surpassed by more efficient networks, VGG's principles of depth and simplicity remain important in CNN design.

## Q11: Describe the Inception/GoogLeNet module.

**A11:** The Inception module processes inputs through multiple parallel paths with different filter sizes (1×1, 3×3, 5×5) and pooling, then concatenates outputs. This allows the network to choose the appropriate filter size for each pattern, rather than committing to a single size. 1×1 convolutions before larger filters reduce computational cost through bottlenecking, making the module efficient despite multiple paths. The module addresses the problem of choosing optimal filter sizes by using all sizes and letting the network learn combinations. Inception modules are stacked to build GoogLeNet, which won ImageNet 2014 with fewer parameters than previous winners. The architecture demonstrates that width (multiple parallel paths) can complement depth, providing another dimension for model capacity. Inception's design philosophy of parallel multi-scale processing has influenced many subsequent architectures.

## Q12: Explain ResNet and skip connections.

**A12:** ResNet introduced residual connections that add input to layer outputs: output = input + block(input), enabling training of very deep networks (100+ layers). Skip connections create identity mappings that allow gradients to flow directly backward, solving the vanishing gradient problem in deep networks. Residual learning reformulates the problem: instead of learning complete transformations, blocks learn residuals (differences from identity), which is easier to optimize. ResNet demonstrated that depth significantly improves performance when training is possible, winning ImageNet 2015 with 152 layers. The architecture uses bottleneck blocks with 1×1 convolutions for efficiency in deeper variants. Residual connections enable networks to learn identity when deeper layers aren't needed, providing flexibility. ResNet's success proved that depth is crucial for performance and that proper architecture enables training of previously impossible depths.

## Q13: What is DenseNet and how does its connectivity work?

**A13:** DenseNet connects each layer to every subsequent layer in a dense block, creating direct connections between all layers rather than just adjacent ones. In a dense block, layer l receives concatenated feature maps from all previous layers [0, 1, ..., l-1] as input. This dense connectivity enables feature reuse: each layer can access all previous features, reducing redundancy and improving parameter efficiency. DenseNet uses bottleneck layers (1×1 convolutions) before 3×3 convolutions to control growth rate and reduce computation. Transition layers between dense blocks use pooling and 1×1 convolutions to reduce dimensions. The architecture achieves strong performance with fewer parameters than ResNet by maximizing information flow and reducing redundant learning. Dense connectivity encourages feature diversity and improves gradient flow, though it increases memory requirements for storing concatenated features.

## Q14: How does batch normalization work in CNNs?

**A14:** Batch normalization normalizes activations within each mini-batch by subtracting mean and dividing by standard deviation, then applies learnable scale and shift parameters. In CNNs, normalization is applied per channel across spatial dimensions and batch, maintaining channel-specific statistics. Batch normalization stabilizes training by reducing internal covariate shift, allowing higher learning rates and reducing sensitivity to initialization. It acts as regularization by adding noise through batch statistics, reducing overfitting. In CNNs, batch normalization is typically placed after convolution but before activation, normalizing the convolutional outputs. During inference, running averages of training statistics replace batch statistics for consistent behavior. Batch normalization enables training of deeper networks and has become standard in modern CNN architectures, significantly improving training stability and convergence speed.

## Q15: What data augmentation techniques are used for vision tasks?

**A15:** Data augmentation artificially expands training datasets by applying transformations that preserve label semantics. Common techniques include random cropping, horizontal flipping, rotation, color jittering (brightness, contrast, saturation), and scaling. Advanced augmentations include mixup (blending images and labels), cutout (randomly masking regions), and AutoAugment (learning optimal augmentation policies). Augmentation helps models generalize by exposing them to variations they'll see at test time, reducing overfitting. It's particularly important when training data is limited, effectively increasing dataset size without collecting more data. Different tasks require different augmentations: classification can use aggressive transformations, while detection/segmentation must preserve spatial relationships. Proper augmentation selection balances between increasing diversity and maintaining label correctness. Data augmentation is a crucial regularization technique that significantly improves CNN performance, often providing larger gains than architectural improvements.

## Q16: Explain transfer learning with CNNs.

**A16:** Transfer learning uses pre-trained CNNs (trained on large datasets like ImageNet) as starting points for new tasks, leveraging learned feature representations. Common approaches include fine-tuning (updating all weights) or feature extraction (freezing early layers, training only classifiers). Early layers learn general features (edges, textures) transferable across tasks, while later layers learn task-specific features. Transfer learning is especially valuable when target datasets are small, as pre-trained features provide strong initialization. It reduces training time and data requirements compared to training from scratch. The choice between fine-tuning and feature extraction depends on dataset size and similarity to pre-training data: similar tasks benefit from fine-tuning, while different tasks may only need feature extraction. Transfer learning has become standard practice, enabling strong performance with limited data and making deep learning accessible for many applications.

## Q17: Provide an overview of object detection: YOLO and R-CNN.

**A17:** Object detection localizes and classifies multiple objects in images, requiring both bounding box prediction and classification. R-CNN (Region-based CNN) uses a two-stage approach: first generating region proposals, then classifying and refining each proposal. Variants like Fast R-CNN and Faster R-CNN improve speed by sharing computation. YOLO (You Only Look Once) uses a single-stage approach, dividing images into grids and predicting bounding boxes and classes directly, making it much faster but potentially less accurate. YOLO treats detection as regression, predicting boxes and classes in one forward pass. R-CNN methods are more accurate but slower, while YOLO prioritizes speed for real-time applications. Modern detectors like RetinaNet combine single-stage efficiency with two-stage accuracy. Object detection requires predicting both spatial locations (bounding boxes) and classes, making it more complex than classification. The choice between approaches depends on accuracy vs speed requirements.

## Q18: Explain semantic segmentation: U-Net and FCN.

**A18:** Semantic segmentation assigns class labels to every pixel, requiring dense predictions rather than single image-level or bounding box outputs. Fully Convolutional Networks (FCN) replace fully connected layers with convolutions, enabling arbitrary input sizes and pixel-level predictions. FCNs use skip connections to combine low-level spatial details with high-level semantic information. U-Net uses an encoder-decoder architecture with symmetric skip connections: the encoder downsamples to extract features, the decoder upsamples to restore resolution, and skip connections preserve fine details. U-Net's U-shaped architecture enables precise localization while maintaining context, making it effective for medical imaging and other tasks requiring pixel accuracy. Both architectures address the challenge of maintaining spatial resolution while incorporating high-level semantics. Semantic segmentation is more computationally intensive than classification, requiring processing at pixel level rather than image level. These architectures enable applications like medical image analysis, autonomous driving, and scene understanding.

## Q19: Compare CNNs with Vision Transformers (ViT).

**A19:** CNNs use inductive biases like translation equivariance and locality through convolutional operations, while Vision Transformers (ViT) apply self-attention to image patches without these biases. ViT divides images into patches, treats them as sequences, and uses transformer architecture with self-attention to model relationships. CNNs excel with limited data due to built-in priors, while ViT requires large datasets but can learn flexible attention patterns. ViT's self-attention provides global receptive fields from early layers, while CNNs build receptive fields gradually. CNNs are more parameter-efficient for small models, while ViT scales better to very large models. Training: CNNs are faster and need less data; ViT needs more data and computation but can achieve better performance at scale. Modern approaches combine both: CNN backbones with transformer heads, or hybrid architectures leveraging strengths of both. The choice depends on data availability, computational resources, and task requirements.

## Q20: What are deformable convolutions?

**A20:** Deformable convolutions learn spatial offsets for sampling locations, allowing filters to adapt their shape to object geometry rather than using fixed rectangular grids. Standard convolution samples from regular grid positions, while deformable convolution samples from learned offset positions, enabling the filter to focus on relevant regions. The offsets are learned through additional convolutional layers that predict sampling location adjustments for each position. This adaptability helps handle object scale, aspect ratio, and rotation variations more effectively than standard convolutions. Deformable convolutions are particularly useful for object detection and segmentation, where objects have diverse shapes and poses. They provide a way to incorporate geometric transformations into the network architecture, learning appropriate sampling patterns for each task. While more computationally expensive than standard convolution, deformable convolutions can improve performance on tasks requiring geometric understanding. The technique demonstrates how learned sampling strategies can outperform fixed geometric operations.
